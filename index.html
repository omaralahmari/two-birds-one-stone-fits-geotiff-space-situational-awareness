ARCHITECTED END-TO-END PATH — Omar Alahmari
Two independent awareness streams are processed, converted into a common spatial context, co-registered, overlaid, and prepared for downstream execution.
1 DUAL INPUT
FITS + GeoTIFF
2 SPACE CALIBRATION
CCDData → CCDProc
Bias / Dark / Flat
3 SPACE DETECTION
Background statistics → DAOStarFinder → high-significance candidates
4 GIS READ
Rasterio → CRS → affine transform → bounds / resolution
5 COORDINATE EXTRACTION
FITS pixel / WCS context + GeoTIFF row / column context
6 MATCH + CONVERT
Coordinate matching → spatial transformation
7 CO-REGISTER + OVERLAY
Common spatial reference → synchronized layers
8 EXECUTE
Situational-awareness output → downstream GIS product
Architected integration: FITS astronomical processing and candidate detection are connected to a GeoTIFF/Rasterio geospatial stream, then brought through coordinate matching, conversion, co-registration, overlay, and downstream execution. For an operational system, celestial FITS coordinates cannot be treated as Earth longitude/latitude by affine conversion alone; WCS/astrometry plus observation time, observer geometry and, where required, range/orbit information provide the rigorous bridge.
